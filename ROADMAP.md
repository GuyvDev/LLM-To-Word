# md2docx — Deployment & Monetization Roadmap

> Last updated: 2026-02-28
> Status legend: ✅ Done · 🔄 In Progress · ⬜ Not Started

---

## Vision

Deploy `md2docx` as a **freemium SaaS** reachable via a **Chrome Extension** and
a **web UI**, backed by a lightweight FastAPI service. Monetize via Stripe with a
free tier (5 conversions / month anonymous, 25 with account) and a Pro tier ($5/mo).

```
Chrome Extension  ──►  FastAPI backend  ──►  md2docx core (Python)
Web UI            ──►        │
                             ├── Supabase  (auth + quota DB)
                             └── Stripe    (payments)
```

---

## Tiers

| Tier | Price | Conversions / month | Watermark | API key |
|---|---|---|---|---|
| Anonymous | Free | 5 (per IP) | Yes | No |
| Free account | Free | 25 | No | No |
| Pro | $5 / mo or $35 / yr | Unlimited | No | Yes |
| Team | $15 / mo | Unlimited (5 seats) | No | Yes |
